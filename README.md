# 오늘은 어떤 날인가요? - 아리아 맞춤 예약 가이드 (시연용 프로토타입)

웨스틴 조선 서울 아리아를 예약하기 전, 고객이 목적(기념일, 가족 모임 등)을 고르면 그에 맞춰 필요한 정보를 한 장의 모바일 페이지로 보여주는 서비스의 **시연용 프로토타입**입니다.

- 신세계그룹 Future & Dream Academy 고객경험 워크숍(1차 프로젝트) 팀 과제용입니다.
- 실제 호텔 서비스가 아니며, 조선호텔앤리조트와 관련이 없습니다.
- 화면의 가격, 할인, 규정 등 모든 정보는 **예시 자리표시자**입니다. 실제 정보가 아닙니다.

## 시연 흐름
문자 수신 → 링크 열기 → 질문 3개(목적, 동행, 시기) → 맞춤 가이드 → 예약하러 가기(시연용 안내)

## 수정 방법
모든 문구와 정보는 `data.js`에서 수정합니다. 실제 정보로 교체할 때는 `[예시]` 표시를 찾아 바꾸세요.
